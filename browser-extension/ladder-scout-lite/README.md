# Botlab 战绩简析（简版，推荐）

进入 Botlab 的用户战绩页，右下角自动显示当前模型：

- 正常战绩、先后手胜和负；
- **可避免失分局数**与本来必败后手正常输的局数；
- 你目前的积分下，两局打平掉几分、两战全胜加几分，以及单组涨分最低要求；
- 最近三个失分证据的回放链接（只在你点击后才打开）。

**不读取每局回放，不逐手求解，不运行 Rust，不做复杂收益预测。**
只读取 `/api/v1/ladder` 的积分，以及该用户的分页 `/api/v1/ladder/series`。
一手镜像开局共7种，本地精确求解器已核对的先手 WDL 为：

```text
先手列（1-based）: 1  2  3  4  5  6  7
预置应手列:       7  6  5  4  3  2  1
预置两手后先手值: 胜 胜 和 胜 和 胜 胜
```

插件只查这张表并对照终局：胜势变和/负、可和变负，才计为可避免失分。
已必败后手输棋不计为破绽。它只能发现终局低于开局目标的情况，不能证明
每手完美，也可能漏掉双方中途相互抵消的失误。

按代码和模型 SHA 区分当前模型，排除旧模型、异常局及未结算记录。
不保存 Cookie，无需额外权限；使用浏览器当前登录态。仅在本页内存缓存
最近6位用户的战绩2分钟，不持久化；刷新按钮会跳过缓存。最多读取400组。

## 安装

1. 解压 ZIP，找到含 `manifest.json` 的 `botlab-ladder-scout-lite` 文件夹。
2. Edge 打开 `edge://extensions`，Chrome 打开 `chrome://extensions`，开启开发人员模式。
3. 点击“加载解压缩的扩展”，选择该文件夹。
4. 登录 Botlab，打开任意用户的计分战绩；已经打开的页需刷新一次。

`↻` 重新读取，`−` 收起，点击小按钮展开。支持网站内前进、后退和切换用户。
简版和详细版二选一安装，避免两个面板重叠。详细版另有情景收益、版本筛选
和我方战绩核对，但同样不逐手求解，也不会自动发起对战。
