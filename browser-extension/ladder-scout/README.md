# Botlab 天梯侦察

进入 `https://botlab.aiphys.cn/ladder/history?player=用户ID`，右下角自动分析
当前模型的战绩、可避免失分及与你对战的 Elo 收益情景。兼容 Edge / Chrome
Manifest V3，不需要服务器或额外账号。

## 安装（Edge / Chrome）

1. 解压发布的 ZIP，找到含 `manifest.json` 的 `botlab-ladder-scout` 文件夹。
2. Edge 打开 `edge://extensions`；Chrome 打开 `chrome://extensions`，开启“开发人员模式”。
3. 点击“加载解压缩的扩展”，选择该文件夹。
4. 在浏览器登录 Botlab，进入任意用户的计分战绩页。已打开的页面需先刷新一次。

在插件图标弹窗中可开关自动分析或清空缓存。面板右上角 `−` 收起为小按钮，
`↻` 跳过缓存重新读取。页面内跳转、前进和后退也会自动识别目标用户。

## 看什么

- **当前模型优先**：按代码 SHA + 模型 SHA 区分版本；不把旧模型的失误
  当成当前模型的破绽。相同内容的重复上传视为同一模型。
- **可避免失分**：只读已正常结束、两局换色的计分系列。对已知一手镜像
  开局，区分胜势变和/负、可和变负，以及正常的必败后手负局。
- **Elo 门槛**：从平台读取你的分数、对方分数及 K 值；显示两战皆负、
  一和一负、两局打平、一胜一和、两战全胜的积分变化。可手动改分数试算。
- **证据回放**：列出当前版本可避免失分的具体比赛，点开即可核对。
- **可挑战状态**：提示当天已计分、对手未上榜、或自己有尚未结束的系列。

默认统计当前模型最近 50 组已结算系列，可选 20/200/全部已读（上限400）。
会自动顺序读取分页，先显示已经读到的样本，读取完成后形成结论。
本机缓存有效 5 分钟；缓存按登录用户分开，最多保留 6 份、约 3.5 MB。

## 收益情景的含义

默认勾选“我方近似最优”：假设你的模型能稳定守住当前局面的最优胜负值。
取对手历史中相对预置开局的可避免失分，估算在可复现这些破绽时，你的
系列平均得分可能从 50% 提升多少，再代入当前 Elo 公式。

这不是实际对战胜率预测，也不是保证涨分。历史对手、施压路线、样本量
和你的模型失误都会影响收益。面板会同时核对我方当前模型历史；如果我方
也出现可避免失分，会把“近似最优”情景标成乐观假设。

取消勾选后，只参考双方**当前模型**的历史交手；没有交手样本则不预测收益。
“未见可避免失分”只表示最终结果没有低于该开局应守住的目标，不是逐手
证明模型完美，双方中途相互抵消的失误可能看不出来。

情景收益逐组计算整数积分变动后求均值，不把平均得分代入再取整。
情景误差带将计分系列近似为独立样本，用整数积分变动范围的 Hoeffding
保守界（α=0.05）；它不覆盖“历史破绽能否在新对局复现”的模型风险。
整数积分按四舍六入五成双近似平台 Python 取整，并用历史结算记录检查公式。

## 数据与权限

只向 `botlab.aiphys.cn` 的天梯 GET 接口读取数据，使用浏览器已有登录态。
不需要复制 Cookie，不读取或保存 Cookie，不嵌入作者的认证信息，不调用
发起对战、修改模型或参赛设置的接口。没有第三方服务、统计或外部脚本。
扩展只申请 `storage` 权限，页面脚本只在 Botlab 域名运行，分析面板只在
战绩页启用。发布包不含抓取到的用户原始数据。

## 开发和测试

```bash
node --test tests/core.test.cjs
```

`core.js` 为无网络、无 DOM 的纯分析函数；`content.js` 负责 GET 分页、缓存、
SPA 路由和 Shadow DOM 面板；`popup.js` 负责本机开关和清缓存。
浏览器测试脚本和验证结果见 `tests/`、`docs/`。

Chrome 扩展机制参考：[Content scripts](https://developer.chrome.com/docs/extensions/develop/concepts/content-scripts)。
