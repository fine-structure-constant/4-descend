# v9 pure solver baseline

Pascal Pons, [Connect 4 solver](https://github.com/PascalPons/connect4),
AGPL-3.0. The Rust engine in native/c4core is derived from this solver.
The embedded static executable is generated by native/make_payload.py.
Corresponding Rust source and build instructions are supplied with this release
in the separate source archive and in experiments/solver_v9.

The complete <=12-disc optimal-move table and the public 7x6.book exact-score
table are inherited from v8. The original 41,661-position midgame table contains exact
per-column WDL labels generated offline with the same C++ solver. v9 adds 202
proved development positions and alternative replies, for 41,863 total entries;
tools/extend_book.py and runs/book_extension.json record this extension. These are
lookup data, not trained parameters. Original data provenance is recorded in
experiments/exact12_v7/REFERENCES.md in the full project.

The Python fallback uses bitboards, non-losing-move pruning, alpha-beta search,
and bounded heuristic search. No neural model, training, remote inference,
or MCTS is used by v9. PyTorch only deserializes the fixed book tensors.

Time-limited searches may remain unresolved. Such actions are marked
bounded_search, not claimed to be perfect. A proved drawing move may be
selected while an unresolved winning move still exists.
