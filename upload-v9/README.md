# v9 纯求解器 Baseline

平台可在“同学对战”中搜索 **v9 纯求解器 Baseline**。最新平台版本为独立 Bot 的 v3，READY。

- `code.zip` + `model.pt`：直接上传，模型文件仅含固定棋谱数据，没有神经网络权重。
- `source.zip`：完整 v9 源码；不重复附带棋谱，请一起保留 `model.pt`。
- `release.json`：平台 ID、包大小和 SHA-256。

纯求解器 + 完整 ≤12 子背谱 + 41,863 个精确中盘局面。没有 CNN 或 MCTS。
初始化及背谱回合预算未来局面，缓存精确动作与搜索结果。时间不足时仍可能未完成证明，不能宣称全局完美。

Rust 在本地可运行，但平台拒绝执行临时目录中的程序。平台实际使用专门验证过的 Python 求解器路径。
最终平台整局自对弈正常结束，42 手和棋，最高每手 CPU 约 0.883 秒，墙钟约 0.904 秒。
这用于验证兼容性，不能作为独立棋力胜率。

比较棋力建议使用已验证为和棋的固定开局并换色。随机预置两手可能直接造成某方必败；
即使完美求解器也不能保证从必败局面战胜不犯错的对手。
